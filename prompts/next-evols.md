# Features

- Référencer tous les donjons (/wakassets/blob/main/jsons/dungeons.json, https://wakfu.wiki.gg/wiki/Dungeon):
    - leur boss 
    - leur image (/wakassets/bossIllustrations)
    - leur tranche (20, 35, 50, etc...)

- historique des échanges :
    - date via tooltip sur icon
    - nom du personnage
    - deux sections (acquis / cédés)
        - icon de l'objet
        - nom de l'objet
        - quantité (acquis ou cédé)

- Détection de double comptes (lorsque les messages du chat sont en double)
